# techc_hack4

## githubとVScodeの連携

1. 開発環境の初期設定（リポジトリのクローン）
GitHub上のリモートリポジトリをローカル環境へ構築する手順。

左の縦列から上から三つ目のソース管理という画面を開く

リポジトリの初期化と書いてあるので押す。その後変更と書かれている項目の横の...を押しクローンを選択

クローンを選択するとどこに保存するか聞かれるので以下の行動をする。

URLの入力: 対象リポジトリURL　https://github.com/atmatsuda/techc_hack4 (コピーペーストしてください)
を正確に入力し、Enterキーを押下する。

2. 機能別ブランチの作成
main ブランチを保護し、安全に開発を行うために作業用ブランチを作成する。

ブランチ作成の開始: VSCode左下のステータスバーにある main をクリックする。
->ない場合は下のほうにある手順を参照。

新規作成: コマンドパレットより Create new branch... を選択する。

命名: 作業内容に応じたブランチ名（例: feature/first-setup）を入力し、Enterキーで確定する。

確認: ステータスバーの表示が、作成したブランチ名に変更されたことを確認する。

3. 変更の保存と同期（コミット・プッシュ）
ローカルでの変更を確定させ、リモートリポジトリへ反映させる手順。

ステージングとコミット:

VSCode左側の「ソース管理（枝分かれアイコン）」を選択する。

変更したファイル(保存してないと出てこない)を確認し、マウスを持っていくと右のほうに
+ボタン(ステージング)が出てくるので押す。
左側の大きな青い「コミット」ボタンを押下し、変更をローカル環境に確定させる。

プッシュ（リモートへの送信）：
違う画面に飛び右下に小さい青いコミットボタンが現れるので一番上の行になにかしら一文字を打って(必須)
　Ctrl+s　してその会話を閉じると

左側の大きな青い「コミット」ボタンが以下のどちらかに代わるので押す。

コミット完了後に表示される「変更の同期（Sync Changes）」または「プッシュ（Push）」ボタンを押下する。

これにより、手元の変更がGitHubサーバーへ反映される。

4. 運用上の留意事項
常にブランチを確認: 作業開始時は、必ず左下のステータスバーを確認し、適切なブランチにいることを確実にする。

URLの取り扱い: GitHubのURLは、記号（(や)、[や]など）を含めずに入力すること。

リポジトリの独立: 既にGitで初期化されたフォルダにクローンを重ねることは避け、クリーンな状態でクローンを実行すること。

5. 左下に main が表示されない場合の対処法
クローン直後やリポジトリを開いた直後に main（ブランチ名）が表示されない場合は、以下の手順で復旧可能です。

リポジトリの再読み込み: VSCodeのサイドバーにある「ソース管理」アイコンをクリックし、メニュー（...）から「リポジトリを更新」を選択する。

フォルダの再確認: 現在開いているフォルダが、クローンしたリポジトリの直下であることを確認する。もしサブフォルダを開いている場合は、一度クローンしたフォルダ自体を「フォルダーを開く」で開き直す。

Gitの認識確認: VSCode下部のステータスバーを右クリックし、「Git」の項目にチェックが入っているか確認する。チェックがない場合は表示が隠れているだけのため、有効化することで確認可能になる。

6. GitHubからのログアウト（セキュリティ対策）
学校のパソコンなどで共有利用する場合、作業終了時に必ず以下の手順でサインアウトを行うこと。

認証情報の削除:

Windowsの検索窓に「資格情報マネージャー (Credential Manager)」と入力し、起動する。

「Windows 資格情報」をクリックする。

一覧の中に git:[https://github.com](https://github.com) という項目があるため、それをクリックして「削除」を実行する。

VSCodeからのサインアウト:

VSCode画面左下の「アカウントアイコン（人のマーク）」をクリックする。

「GitHub」を選択し、「サインアウト」を実行する。

キャッシュのクリア（推奨）: パソコンを共有する場合、最後にブラウザの履歴およびCookieを削除し、ブラウザ上のGitHubからも確実にサインアウトしておくこと。
