[気まずさ撃退！即効トークおみくじ（仮）] 要件定義書
1. システム概要
目的・コンセプト： 「沈黙の気まずさ」というペインを、ボタン一発でおみくじからユニークなお告げと話題を授かる体験によって笑いへと昇華させる沈黙レスキューWebツール。

動作環境： XAMPP環境（URL: http://localhost:8000/techc_hack4/）

2. 機能要件（今回実装する対象）
[ ] シチュエーション選択＆おみくじ機能（難易度：レベル2 - 固定のシチュエーションカテゴリからランダムで話題を1件取得・表示）

[ ] 端末内履歴表示機能（難易度：レベル3 - Cookie/LocalStorageを活用し、同一端末で過去に引いた話題履歴を保持・閲覧）

[ ] ユーザー話題投稿機能（難易度：レベル2 - シチュエーション選択、話題本文[50文字以内]、ニックネーム[15文字以内]を入力して匿名投稿。初期状態は未承認）

[ ] 簡易アクセス制限付き管理者精査画面（難易度：レベル2 - 秘密のURLパラメータ検証＋BASIC認証のハイブリッドによる簡易アクセス制限のもと、投稿された話題の「承認/非表示」を切り替え）

[ ] テキストベース管理者インサイト機能（難易度：レベル2 - SQLのCOUNTやGROUP BYを用いた集計により、カテゴリ別話題数や引かれた回数をテキスト/数値で一覧表示）

3. 非機能要件・セキュリティ要件
セキュリティ要件詳細：

① 入力値検証（バリデーション）方針： 話題本文（50文字以内）、ニックネーム（15文字以内）、シチュエーション選択の必須チェックを実施

② 表示時のサニタイズ（エスケープ）方針： ユーザー投稿テキスト出力箇所全般に対して htmlspecialchars を適用し、XSS（クロスサイトスクリプティング）を防止

③ データベースセキュリティ（PDO適用）方針： PDOのプリペアドステートメント（プレースホルダー）を徹底し、SQLインジェクションを防止

④ 認証と保護方針： 秘密のURLパラメータ（例: ?key=secret123）とBASIC認証を併用して管理者エリアを保護

エラーハンドリング方針： DB接続失敗やSQL実行エラー発生時に生のシステムパスやSQL文を表示せず、「システムエラーが発生しました。時間を置いて再度お試しください。」等の汎用エラーメッセージを出力

4. 今回スコープアウト（削除）した機能
一般ユーザーログイン・会員登録機能（判断理由：Cookie/LocalStorageを用いた端末内履歴保存で代替し、開発工数を削減するため）

グラフィカルな管理者インサイト表示（Chart.js等のライブラリ活用）（判断理由：開発期間を考慮し、SQL集計による数値・テキスト表示に仕様を削減するため）

SNSシェア・カード生成（Canvas操作/動的画像生成機能）（判断理由：レベル4〜5に該当する応用機能であり、コア機能の完成度を高めるため今回は実装を見送るため
