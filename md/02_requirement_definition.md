# デザトレ（DesaTre） 要件定義書

## 1. システム概要

* **目的・コンセプト：** Webデザインを学ぶ学生向けに、ランダムなお題の提示、Figma URLによる提出、模擬AIによる採点・フィードバック生成を行い、デザイン学習の習慣化と成長記録をサポートするWebシステム。匿名ギャラリー機能を通じて周囲の目を気にせず安心して練習できる環境を提供する。
* **動作環境：** XAMPP環境（URL: `http://localhost/techc_hack4-main/login.php`）
* **フォルダ名：** `techc_hack4-main`
* **データベース名：** `techc_hack4-main_db`



## 2. 機能要件（今回実装する対象）

* [ ] **ユーザー管理機能（難易度：レベル3 - 実務標準）**
* 新規会員登録（ユーザー名、メールアドレス、パスワード）
* ログイン／ログアウト処理（セッション管理）


* [ ] **ランダムお題表示機能（難易度：レベル2 - 基本）**
* `topics` テーブルからランダムにお題（タイトル、説明文、難易度、カテゴリ）を取得して画面に表示


* [ ] **Figma URL提出＆模擬AI採点機能（難易度：レベル2 - 基本）**
* Figma共有URLを入力して提出
* 提出時にPHP側でランダムなスコア（75〜95点）とあらかじめ用意された定型フィードバック文面を自動生成して保存


* [ ] **マイページ・成長可視化機能（難易度：レベル2 - 基本）**
* これまでの提出回数（`COUNT`）および平均スコア（`AVG`）の数値表示
* プロフィール情報（ユーザー名、ひとこと自己紹介等）の表示


* [ ] **匿名作品ギャラリー機能（難易度：レベル2 - 基本）**
* 他のユーザーが提出したFigma URLおよび獲得スコア・AIフィードバックを匿名一覧で閲覧


* [ ] **データベース設計（難易度：レベル2〜3 - 基本〜実務標準）**
* `users` テーブル（ユーザーID、メールアドレス、パスワードハッシュ、表示名、アイコン画像名、ひとこと、登録日時、最終ログイン）
* `topics` テーブル（お題ID、タイトル、説明文、難易度、カテゴリ、作成日時）
* `submissions` テーブル（提出ID、ユーザーID、お題ID、Figma URL、総合スコア、AIフィードバック文面、ステータス、提出日時）


* **具体性の高い課題（お題）の動的無限生成**:
  * 「高級和食専門店のトップページ」「ポートフォリオのヘッダー」等、ターゲット・目的・制作範囲を限定した具体性の高いお題を動的にランダム生成・更新する機能。
* **高解像度なカテゴリ別AIフィードバック**:
  * 視認性・余白（Padding/Margin）・タイポグラフィ（ジャンプ率・カーニング）・CVR導線・コンポーネント構造など、項目別に具体的かつ実践的な解説文章を出力する。

  * **同一URL決定論的評価 ＆ 差分比較フィードバック機能**:
  * 同一Figma URLにおける初回提出時は、URLハッシュに基づき決定論的な再現性のあるAIスコアおよび初期フィードバックを出力。
  * 同一Figma URLの再提出時は、データベースから前回提出データ（スコア・フィードバック）を取得し、前回からの改善度（スコア加点）および変化点に着目したフィードバックを生成。
* **お題コンセプト・ターゲット適合性判定**:
  * お題のターゲット層（年代・属性・用途）およびトーン＆マナー（和風・高級感・アクティブ等）に対するデザインの適合性を判定し、不整合がある場合は改善点としてフィードバック出力する。

  - **Figmaサムネイル自動取得連携機能（新機能）**
  - ユーザーが提出したFigma URLから `file_key` を解析・抽出し、Figma REST API (`GET /v1/files/:key`) をバックエンドから非同期/同期で呼び出し。
  - ファイルのファーストビューまたはキャンバスのプレビュー画像（サムネイルURL）を自動取得し、ギャラリーおよびマイページに描画する。
  - APIエラー時やアクセストークン未設定時は、フォールバック用のダミープレビュー画像を表示して描画崩れを防ぐ。

 **Figma OAuth 2.0 アカウント連携機能**
   - 外部認可エンドポイントとの通信によりアクセストークンを取得・保持し、安全な認可状態を確立する。
 **REST API経由でのサムネイル自動生成・同期機能**
   - 提出されたFigma URLから `file_key` を自動抽出し、バックエンド（cURL）経由でFigma APIから高精細サムネイルURL（`thumbnailUrl`）を取得・DBへ保存する。
   - マイページおよび匿名ギャラリーにおいて、取得したサムネイルをカード型UIへ動的に即時反映する。

  


## 3. 非機能要件・セキュリティ要件（★意識強化項目）

* **セキュリティ要件詳細：**
* **① 入力値検証（バリデーション）方針：** 必須項目の未入力チェック、メールアドレス形式チェック、URL形式チェックをサーバー側（PHP）で実施。
* **② 表示時のサニタイズ（エスケープ）方針：** XSS対策のため、画面にユーザー入力値やDBからの取得値を表示する際は必ず `htmlspecialchars()` を適用。
* **③ データベースセキュリティ（PDO適用）方針：** SQLインジェクション対策のため、すべてのDB操作においてPDOのPrepared Statement（プリペアドステートメント）を徹底使用。
* **④ 認証とパスワード保護方針：** パスワードは `password_hash()` 関数を用いて暗号化（ハッシュ化）してDBに保存。


* **エラーハンドリング方針：** DB接続エラーや生SQLエラー、サーバー内部の絶対パスを画面に表示せず、「システムエラーが発生しました。時間を置いて再度お試しください」といった汎用エラーメッセージを表示する。

### 3.1 UI/UX要件
* **共通スタイルシート（CSS）の集約と統一**: 
  * インラインスタイルを廃止し、`css/style.css` にスタイル定義を一元管理する。
  * CSS変数（`--primary-color`, `--card-bg` 等）を活用し、システム全体のデザインの統一性を維持する。
* **カード型レイアウトおよびホバーエフェクトの採用**: 
  * ギャラリー画面や各種フォームにおいて、直感的に操作しやすいカード型UIを採用する。
  * ホバー時に視覚的フィードバック（`translateY` による浮き上がりアニメーションおよび影の設定）を提供する。
* **レスポンシブデザイン対応**: 
  * CSS Grid (`grid-template-columns: repeat(auto-fill, ...)` ) を導入し、PC・タブレット・スマートフォン等の各種画面サイズに最適化されたレイアウトを提供する。

## 4. 画面一覧および画面要件

| 画面名 | ファイル名 | 画面概要・デザイン要件 |
| :--- | :--- | :--- |
| ホーム / お題提出 | `index.php` | 本日のお題表示、Figma URL入力フォーム、AI審査員（ペルソナ）選択フォーム、カードコンテナ構造 |
| ギャラリー | `gallery.php` | 全ユーザーの提出作品一覧。CSS Gridによるカード並列表示、スコアバッジ、Figmaへの外部リンク |
| マイページ | `mypage.php` | ユーザーの学習スタッツ（提出回数・平均スコア）のカード表示、過去の提出履歴テーブル |
| ログイン | `login.php` | ログインフォーム、エラーメッセージ表示、コンテナ型カードレイアウト |
| 新規会員登録 | `register.php` | アカウント作成フォーム、バリデーションエラー表示、コンテナ型カードレイアウト |

## 5. 今回スコープアウト（削除）した機能

* **外部AI API（OpenAI API Visionモデル等）とのリアルタイム連携（判断理由：レベル5の実務発展機能であり、APIキー管理・プロンプト調整・通信エラー対策などの開発コストが期間を超えるため）**
* **画像ファイル自体のアップロード＆サーバー保存処理（判断理由：レベル4の応用機能。今回はFigma URL入力形式に簡略化し、レベル2まで工数を削減）**
* **リアルタイム上位％（パーセンタイル）計算・複雑なスコア推移グラフ（Chart.js等）（判断理由：レベル4〜5の機能であり、SQL集計クエリおよびフロントエンドライブラリの実装コストが高いため数値表示に簡略化）**

### 5.1 全画面共通デザインポリシー（シックテーマ適用）
* **トーン＆マナー**: 深みのあるスレートブラック（`#0f172a`）およびチャコール（`#1e293b`）を基調としたシックなダークUIに統一。
* **主要画面のUI改修**:
  * **ホーム / お題提出 (`index.php`)**: ヘッダーナビゲーションおよびカードコンテナ、ペルソナ選択UIをシックなスタイルに統合。
  * **マイページ (`mypage.php`)**: 学習スタッツ（総提出回数・平均スコア）を視認性の高いダークカードで表示し、提出履歴テーブルもダークトーンに刷新。
  * **ログイン (`login.php`) / 会員登録 (`register.php`)**: 画面中央配置のコンパクトなダークカード型レイアウトを採用し、入力フィールドやエラー表示の視認性を向上。
